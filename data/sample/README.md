# Sample datasets

| File | Records | What |
| --- | --- | --- |
| `off_india_subset.jsonl` | 466 | **Real Open Food Facts records**: products tagged `en:india` in the five categories that declare at least 4 of energy, sugars, saturated fat, sodium, fat and protein. Filtered on 12 Oct 2026 from the official export `en.openfoodfacts.org.products.csv` (AWS Open Data) with `scripts/off_export_to_jsonl.py`. Open Food Facts has no prices, so these records have none. |
| `synthetic_products.jsonl` | 40 | **Synthetic demo records** (not real products) with made-up prices, so value-for-money and price-based alternatives can be shown. Names start with "Sample", brands with "Demo Brand", codes with `SYN-`; labelled synthetic in the API and UI. Generated by `scripts/make_synthetic_sample.py`. |

Load: `python -m database.ingest data/sample/off_india_subset.jsonl` (or `./run.sh seed`, which loads both).
The full India extract (2,692 records, including ones with little nutrition data) is reproducible with the
command in `scripts/off_export_to_jsonl.py` and is git-ignored under `data/raw/`.
