# Indian packaged-food data source audit

**Task:** 2A-1 research and profiling only  
**Checked:** 16 November 2026  
**Production data imported:** no  
**External dataset files saved:** no

This audit separates facts found in source documentation from files independently profiled in this workspace. Several publishers expose a download link but the browser research environment did not expose the binary payload or full file listing; those records are marked publisher-reported, not independently profiled. Counts should be refreshed from each source manifest/snapshot before acquisition.

## Market-discovery articles (not datasets)

- [Listberg’s “Top 100” article](https://listberg.com/article/indias-top-100-fmcg-grocery-products-and-brands-brands-shaping-everyday-indian-consumption) explicitly says its list is curated and **not** an independently audited national sales, market-share or revenue ranking. It mixes foods with personal care/home care. Use only food examples as discovery leads and verify products/manufacturers from primary sources.
- [RateOmatic’s FMCG guide](https://www.rateomatic.in/blog/what-are-fmcg-products-complete-list-and-categories) is a broad editorial list spanning food/beverage, personal care, home care, household and hygiene. Its food examples can seed categories/brand searches; it is neither a product source of truth nor a licensed product dataset. Filter non-edible categories out.

## Acquisition decision

1. Use OFF as the main product-discovery baseline; keep its source lineage and license obligations.
2. Treat PackSense and Shelfpedia as OFF-derived alternative views/quality filters, **not additive product counts**.
3. Use OpenMRP only after live dump/profile verification for barcode/pack/MRP cross-checks; MRP is not a retailer selling price.
4. Profile the Mendeley CSV before trusting or importing its 852 publisher-reported rows/prices.
5. Use the label-variant dataset only as a versioned normalization reference. Use INDB for food/recipe background only.
6. Obtain packaged-food ingredient/nutrition values from the exact product variant’s label or manufacturer source; save page/label provenance and capture time.
